Chevron Agent: Interim Findings

An interim report

The aim of Chevron Agent is to build an agent that can adapt without casually overwriting what it has already learned.

The proposed architecture separates two questions that ordinary attention tends to combine. Retrieval asks, “Which memory appears relevant?” Assent asks, “Should that memory be trusted here?” Evidence that is retrieved but not accepted becomes explicit residual mass. Instead of being discarded or written immediately into long-term memory, it can enter a small provisional buffer while the agent waits for consequences.

This is inspired by the stability–plasticity problem and the vigilance and reset ideas in Adaptive Resonance Theory, rebuilt inside a small differentiable attention-like architecture.

The experimental line now covers ten compact stages. They do not demonstrate a general agent or a persistent artificial self, but they clarify how more than one kind of unresolved evidence should be handled.

The experiments in one line each

Experiment 1 — Causal factorisation

With retrieval held fixed, independent A/N assent distinguished a compatible memory from an incompatible one; ordinary attention and a second retrieval computation could not. This established that retrieval and assent are mathematically and causally different operations.

Experiment 2 — Learned assent

A small supervised Chevron gate learned to accept familiar content and reject “none of the above” cases, reaching 91.5% held-out accuracy against 33.5% for the parameter-matched retrieval-twice control. Assent was learnable when given direct compatibility evidence.

Experiment 3 — The provisional buffer

In a delayed-outcome task, Chevron retained all eight established categories and learned all four new ones without premature writes. Putting candidates directly into retained memory caused repeated overwrites, while a buffer only one or two entries deep was enough to protect established knowledge.

Experiment 4 — Learning from delayed reward

The first reinforcement-learning bridge was less successful. The buffer prevented premature writes, but sparse delayed reward did not teach the assent gate a sufficiently useful mismatch signal. Increasing buffer capacity did not solve the problem.

Experiment 5 — Retrospective reward

Training assent retrospectively when the delayed outcome arrived also failed to produce a well-calibrated gate. A fixed content-based controller could solve the task, showing that the environment and memory capacity were not the main limitations.

Experiment 5a — Isolating the gate

This was the decisive positive result. We removed the unsuccessful learned projections and supplied a meaningful fixed cosine geometry while leaving the Chevron gate, residual mass and buffer intact. Across 100 fresh lifetimes, Chevron retained 97.2% old-context accuracy, reached 89.6% novel-context accuracy, promoted 3.92 of four new contexts and made no premature writes. Immediate writing reached only 35.2% novel accuracy. This localised the problem: the gate and buffer work when the comparison geometry is meaningful.

Experiment 6 — Learning geometry from temporal similarity

A compact contrastive encoder reconstructed much of a hidden latent geometry without category, reward or compatibility labels. It raised geometry correlation from 0.453 to 0.784 and Chevron return from 0.346 to 0.732. That was encouraging, but it missed the frozen confirmation criteria, and automatic gate calibration did not close the gap.

Experiment 7 — Learning geometry by predicting action-conditioned transitions

The forward model successfully predicted next states, producing a strong 0.643 separation between true and permuted next embeddings. Yet its representation was less useful for Chevron than the simpler temporal encoder: return fell from 0.738 to 0.700 and novel-context accuracy from 0.753 to 0.632. Predicting what comes next did not necessarily organise states according to whether the same memory or policy should be trusted.

Experiment 8 — Consequence similarity is not memory identity

A dense consequence objective raised consequence-geometry correlation from 0.107 to 0.488, but Chevron return reached only 0.611, below 0.699 for temporal geometry. More decisively, supplying the exact consequence signature directly to the gate still produced only 0.494 return. Distinct memories can have similar affordances, while noise can alter an outcome profile without changing the situation’s identity. Consequence similarity therefore could not safely serve as the single geometry for both recognising a memory and deciding whether its policy should be trusted.

The later experiments first established an important distinction. Memory identity asks whether this is the same kind of situation. Policy compatibility asks whether the retained response is still appropriate. A changed policy should not automatically create a new identity, and a genuinely new identity should not be treated merely as a policy reversal. The architecture therefore retained separate identity and policy residuals, with typed provisional candidates and different consolidation destinations.

Experiment 9a — Separate queues or more capacity?

Novel-identity candidates and policy-revision candidates were tested in either one shared buffer or two fixed queues. Separate queues did not help. At equal total capacity, a split 4+4 layout matched rather than beat a shared eight-entry bank and produced slightly more evictions. The important change was capacity: increasing the shared bank from four to eight entries raised return from 0.587 to 0.725 and novel accuracy from 0.598 to 0.864. The architectural lesson was to keep candidate types distinct while allowing them to share flexible provisional capacity.

Experiment 9b — Fresh-seed capacity confirmation

The shared-capacity result passed every predeclared criterion across 100 untouched lifetimes. Shared 8 improved return over Shared 4 by 0.156, reversed-context accuracy by 0.164 and novel-context accuracy by 0.278, while reducing evictions by 76.7%. It made no premature writes, established-memory overwrites or duplicate identities. It was also non-inferior overall to rapid identity-only adaptation: slightly slower on deterministic reversals, but significantly better at acquiring novel identities.

Experiment 10 — Retrospective policy assent without an oracle policy signal

The agent now had to discover an obsolete policy from delayed reward with 10% misleading outcomes. Protected Chevron learned 3.96 of four reversals, retained 94.8% stable accuracy and cut false stable-policy revisions from 16.87 under immediate writing to 0.06. It paid a 0.042 return cost against direct value adaptation but remained within the frozen margin and improved novel probes by 0.055. The complete confirmation nevertheless failed one invariant: two noisy provisional candidates became recognisably similar to established identities after averaging but were still allocated as duplicates. The next correction is to recheck identity assent immediately before permanent allocation.

Experiment 10a — Assent again before consolidation

The promotion-time recheck passed every frozen criterion on 100 untouched lifetimes. The original path created one duplicate; the corrected path reconciled that candidate with established memory and created none. Return changed by less than 0.0001, retention was unchanged within 0.0002, and reversed and novel probes were identical. Novelty is therefore provisional twice: evidence may enter the buffer as unresolved, but it must still be novel after accumulation before it can alter permanent memory.

Architecture update

The resulting design does not use two rigid provisional queues. It uses:

separate identity and policy residuals;

typed candidates that remember why they were deferred;

different consolidation destinations for new identities and revised policies;

one flexible shared provisional bank; and

enough effective capacity for the combined unresolved traffic.

Eight entries is not proposed as a universal constant. It was the confirmed capacity for this compact workload. In a larger agent, effective capacity might respond to sustained residual mass, occupancy or eviction pressure.

The broad result

The strongest result is not that Chevron Agent has solved agency. It is that the experiments have isolated a specific and testable architectural result.

Retrieval and assent can be separated. Rejected retrieval mass can be represented explicitly. A small provisional buffer can prevent unresolved experience from immediately altering established memory. When the assent comparison is made in a behaviourally meaningful geometry, these components combine strong retention with successful acquisition of new contexts.

In the original single-residual task, the bottleneck was not the sigmoid gate, its threshold or buffer size; it was learning what compatibility should mean. The later dual-residual task adds a qualification: once identity novelty and policy revision arrive together, provisional capacity must be sufficient for their combined traffic.

That distinction matters. Experiment 7 shows that a representation may be excellent for prediction while still being poor for judgement. Two states can be easy to predict in the same coordinate system without being equivalent for action. Chevron needs a geometry of consequences: are the same actions available, do they lead to similar outcomes, and should the same retained policy apply?

What we can claim

On a compact delayed-context task, a parameter-free Chevron assent gate operating in a meaningful cosine geometry combined high retention with reliable acquisition. Its provisional buffer decisively outperformed immediate writing across 100 fresh lifetimes, while separate write permission provided a smaller additional protection benefit.

On the later combined novelty-and-reversal task, separate identity and policy residuals with a typed shared provisional bank preserved stable knowledge, revised familiar policies and acquired new identities without premature writes or duplicate memories. Adequate shared capacity decisively outperformed an undersized bank across 100 untouched lifetimes and was non-inferior overall to rapid identity-only value adaptation.

This remains a synthetic result. The observations are compact, the action space is small, rewards are deterministic and the successful comparison geometry was supplied rather than learned. We have not yet demonstrated visual learning, spatial agency, a stable personality or a persistent core self.

What comes next

The next experiment should retain the confirmed typed shared bank and learn the two relations separately. Persistence or temporal identity should answer whether the current situation belongs to an existing memory. Sampled consequences should answer whether the retained policy remains appropriate. Experiment 8 showed that consequence similarity alone cannot safely perform both jobs.

If those learned relations recover the fixed-geometry result, the project will be ready for a small spatial world involving traps, shortcuts and changing conditions. Such a world would let the internal metrics become visible behaviour: an agent cautiously withholding assent, preserving an established preference, discovering an exception and eventually consolidating it.

That would still be a long way from a general agent. But the path is now narrower and more empirical than when we began. The immediate question is no longer whether a system should separate retrieval from assent. It is whether it can learn, from experience, what deserves assent.

Appendix: The mathematical implementation used here

The experiments did not replace the general Chevron Attention equations. They fixed several choices that had previously been left open.

Retrieval produced a distribution alpha over established memories using broad address information. In these compact tasks the address families were supplied rather than learned through Q and K projections. Assent then compared current diagnostic evidence A with the retained content N_j of each retrieved slot.

The successful geometric experiment used normalised half-cosine mismatch:

M_j = 0.5 × (1 − cosine(A, N_j))

Read assent was:

r_read_j = sigmoid(40 × (0.19 − M_j))

The admitted mass for a slot and the total unresolved mass were:

w_j = alpha_j × r_read_j

q = 1 − sum(w_j)

Write permission used the same comparison but a stricter threshold:

r_write_j = sigmoid(40 × (0.14 − M_j))

This creates a positive safety margin: evidence may influence the present decision without receiving equal permission to revise retained memory. High q, combined with the absence of a strongly admitted established memory, caused the observation to enter provisional storage. Promotion occurred only after delayed evidence supplied sufficient support.

The general specification also defines a per-slot residual, u_j = alpha_j × (1 − r_read_j). This records which retrieved slot rejected the evidence. In the successful experiment, however, allocation was driven by the aggregate q and the provisional buffer stored the observation rather than making additional behavioural use of the complete u vector. These results therefore support explicit unresolved mass and provisional buffering, but do not establish that retaining a full per-slot residual vector is superior to scalar q.

Experiments 6 and 7 did not alter these gate equations. They changed only the representation supplied to the cosine comparison: first a temporal-contrastive encoder, then an action-conditioned predictive encoder. Their shortfall therefore concerns learning a behaviourally meaningful comparison geometry, rather than a further change to the Chevron gate itself.

The later dual-relation experiments introduced a second assent question rather than changing the original sigmoid form. Identity assent produced q_identity for new-memory allocation. Conditional policy assent produced q_policy for vetoing or revising the policy of an already recognised memory. Both kinds of rejected evidence entered one typed provisional bank. The confirmed implementation increased that bank from four to eight entries for the combined workload; it did not change the read threshold, gate slope or delayed support requirement.

A note on cosine, phase and the R-rule

The use of cosine also creates a geometric connection with the earlier R-rule intuition. For normalised A and N vectors, let phi be the angle between them:

cos(phi) = A dot N

The half-cosine mismatch can then be rewritten using the half-angle identity:

M = 0.5 × (1 − cos(phi)) = sin²(phi / 2)

This gives the gate a simple phase-like interpretation. When A and N point in the same direction, phi is zero, mismatch is zero and assent is strong. At right angles, mismatch is 0.5. When they point in opposing directions, mismatch reaches one and the retained interpretation is strongly rejected.

Under the fixed thresholds used in Experiment 5a, the read boundary M = 0.19 corresponds to an angular separation of approximately 52 degrees. The stricter write boundary M = 0.14 corresponds to approximately 44 degrees. A memory may therefore be sufficiently aligned to influence the current action while still not being sufficiently aligned to revise N.

This resembles the trigonometric language of the R-rule, but the roles should not be conflated. In the R-rule, phase controls the complementary participation of A and N. In the present Chevron gate, relative angle measures representational agreement between them. A future formulation might relate participation phase to agreement phase, but the current experiments establish only the vector-geometric interpretation. They are not evidence that A and N implement biological oscillatory phase.
